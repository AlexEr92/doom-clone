# Задачи: мультиплеер

Разбивка [plan-multiplayer.md](../plan-multiplayer.md) на отдельные задачи.
Именование: `<неделя>-<номер>-<слаг>.md`.

Целевая конфигурация: **до 10 игроков**, основной режим — **deathmatch**,
co-op вторым режимом.

Требования к производительности, задержке, лимитам и тестированию —
в [requirements.md](../requirements.md). Критерии приёмки в задачах
их не дублируют и не отменяют.

Порядок важен: недели 5–6 не трогают сеть вообще и проверяемы в одиночной
игре. Задача 05-04 (мировой хитскан) — жёсткая предпосылка всего остального.
