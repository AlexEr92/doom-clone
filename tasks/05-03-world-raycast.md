# 05-03 — Мировой DDA без фреймбуфера

**Неделя:** 5 — Развязка симуляции и рендера
**Зависит от:** 05-01
**Блокирует:** 05-04, 08-05
**Оценка:** ~120 строк нового кода

## Контекст

DDA сейчас живёт только внутри `raycast_render()` (`raycast.c`) вперемешку с
текстурированием и записью в `zBuffer`. Проверка линии видимости в
`enemy.c:54-70` — отдельная упрощённая реализация с шагом 0.1 клетки,
которая может пропускать углы стен.

Нужна одна переиспользуемая функция трассировки, ничего не знающая ни про
экран, ни про SDL.

## Что сделать

- [ ] Создать `src/raycast_world.c` / `.h`:
  ```c
  typedef enum { HIT_NONE, HIT_WALL, HIT_ENEMY, HIT_PLAYER } HitKind;

  typedef struct {
      HitKind kind;
      int   id;          /* индекс врага/игрока; для стены — не задан */
      float dist;        /* перпендикулярная дистанция */
      float x, y;        /* точка попадания */
      int   side;        /* 0 = X-грань, 1 = Y-грань (для рендера) */
  } RayHit;

  /* Только геометрия уровня: стены и закрытые двери. */
  RayHit raycast_walls(const Map *m, const DoorList *dl,
                       float ox, float oy, float dx, float dy, float maxdist);

  /* Есть ли прямая видимость между точками (обёртка над raycast_walls). */
  int world_line_of_sight(const Map *m, const DoorList *dl,
                          float x0, float y0, float x1, float y1);
  ```
- [ ] Перенести сам DDA-цикл из `raycast.c` в `raycast_walls()`, сохранив
      коррекцию fish-eye (`perpWallDist`) и учёт дверей через
      `map_is_wall_door()`
- [ ] `raycast_render()` переписать поверх `raycast_walls()`: он остаётся
      ответственным за текстурирование, затенение сторон и заполнение
      `zBuffer`
- [ ] `enemy.c:54-70` — заменить самописный `line_of_sight()` на
      `world_line_of_sight()`, старую функцию удалить

## Затрагиваемые файлы

`raycast_world.c/.h` (новые), `raycast.c`, `enemy.c`, `CMakeLists.txt`

## Критерий готовности

- [ ] В `raycast_world.c` нет `#include "engine.h"`, нет `SCREEN_W`,
      нет `zBuffer`, нет SDL
- [ ] Картинка после рефакторинга пиксель в пиксель совпадает со старой
      (сравнить скриншот из одной и той же позиции)
- [ ] Враги замечают игрока и теряют его так же, как раньше; углы стен
      больше не «простреливаются» видимостью

## Замечания

Добавить в `CMakeLists.txt:25-42` новый файл в список исходников.

Точность имеет значение: старый `line_of_sight()` семплирует с шагом 0.1 и
на длинной дистанции может проскочить тонкий угол. Честный DDA это чинит —
поведение ИИ слегка изменится (станет строже), это ожидаемо.
