# 08-04 — Отладочный оверлей сети (F3)

**Неделя:** 8 — Качество netcode
**Зависит от:** 07-05
**Блокирует:** —
**Оценка:** ~100 строк нового кода

## Контекст

Netcode невозможно отлаживать вслепую: «дёргается» — это может быть потеря
пакетов, расхождение предсказания, нехватка снапшотов для интерполяции или
просадка тикрейта сервера. Нужны цифры.

Задачу стоит делать **до** 08-01/08-02, а не после — она окупается сразу.

## Что сделать

- [ ] Клавиша F3 — переключение оверлея (добавить в `input.c:14-35`)
- [ ] Отрисовка поверх HUD существующим шрифтом 3×5 из `game.c:8-48`
      (вынести `draw_text()`/`draw_char()` из `game.c` в общий модуль —
      сейчас они `static` и недоступны снаружи)
- [ ] Показывать:
  ```
  PING 42MS  LOSS 0.3%
  SNAP 20HZ  BUF 3  AGE 105MS
  PRED ERR 0.02  MAX 0.31  FIXES 4/S
  TICK 12480  SRV 12483  DRIFT -3
  SIZE 812B  UP 2.1KB/S  DOWN 19.4KB/S
  ```
- [ ] Источники: `net_peer_rtt()`/`net_peer_loss()` из 07-02, счётчики в
      клиенте, размеры пакетов, расхождение из 08-03
- [ ] График расхождения предсказания за последние ~3 с (простая
      столбчатая диаграмма из `fb_vline()`, `engine.h:20`)
- [ ] Опция запуска `--netlag <ms> --netloss <pct>` — искусственные задержка
      и потери на стороне клиента, чтобы не поднимать `tc netem` каждый раз.
      Это основной инструмент проверки сетевых требований
      ([requirements.md](../requirements.md), раздел 9)
- [ ] Опция `--novsync` — рендерер создаётся с `SDL_RENDERER_PRESENTVSYNC`
      (`engine.c:25`), из-за чего FPS упирается в частоту монитора и
      требования P1/P2 замерить невозможно

## Затрагиваемые файлы

`net_debug.c/.h` (новые), `text.c/.h` (новый — вынесенный шрифт),
`game.c`, `input.c`, `net_client.c`

## Критерий готовности

- [ ] F3 включает/выключает оверлей, не влияя на FPS заметно
- [ ] Цифры сходятся с реальностью: `--netlag 150` показывает ~150 мс пинга
- [ ] `tc netem loss 10%` отражается в счётчике потерь
- [ ] Оверлей работает и на хосте (для локального игрока пинг 0)

## Замечания

Вынос шрифта из `game.c` в `text.c` — небольшой рефакторинг, но нужен и
для скорборда (09-03), и для меню с вводом IP (09-04). Логично сделать
именно здесь.

Встроенные `--netlag`/`--netloss` заметно быстрее в итерациях, чем `tc`:
не требуют root и работают одинаково на всех платформах.
