# 09-01 — Пул точек спавна

**Неделя:** 9 — Deathmatch, геймплей и меню
**Зависит от:** 06-02
**Блокирует:** 09-02, 09-07
**Оценка:** ~90 строк изменений

## Контекст

`map.h:13-19` знает единственную точку старта (`start_x`, `start_y`,
маркер `P` в `assets/maps/level1.txt`). Для 10 игроков нужен пул точек,
причём **не закреплённых за игроками**: в deathmatch игрок возрождается
многократно, и каждый раз точка выбирается заново по обстановке.

Именно поэтому маркеры вида `1`–`4` не подходят: точка спавна — это ресурс
карты, а не свойство игрока.

## Что сделать

- [ ] Новый маркер `s` в формате карты — точка спавна; клетка проходима.
      Буква `P` остаётся стартом solo-режима
- [ ] В `Map`:
  ```c
  #define MAX_SPAWNS 24
  typedef struct { float x, y, angle; } SpawnPoint;
  /* ... */
  SpawnPoint spawns[MAX_SPAWNS];
  int spawn_count;
  ```
- [ ] `map_load()` (`map.c`) — разбор маркера `s`
- [ ] Fallback: если точек `s` нет — сгенерировать из свободных клеток,
      жадно разнося друг от друга (первая случайная, каждая следующая —
      дальняя от уже выбранных)
- [ ] Начальный угол: в сторону наибольшего свободного пространства,
      чтобы игрок не возрождался лицом в стену
- [ ] Выбор точки при спавне и респавне:
  ```c
  const SpawnPoint *world_pick_spawn(const World *w, int player_id);
  ```
      Скоринг по каждой точке, побеждает максимальный:
  - `+` минимальная дистанция до ближайшего живого игрока (главный вес)
  - `−` штраф, если точка в прямой видимости живого игрока
  - `−` штраф за близких живых врагов (в co-op сержант с `attack_range 6.0`
    убьёт на респавне)
  - `−` штраф, если игрок недавно (< 10 с) уже спавнился здесь
- [ ] Точек нужно **минимум вдвое больше**, чем игроков: при 10 игроках
      и 10 точках выбирать становится не из чего. Целевое — 16–20

## Затрагиваемые файлы

`map.h/.c`, `world.c/.h`, `assets/maps/`, `docs/plan-multiplayer.md`

## Критерий готовности

- [ ] 10 игроков заходят на карту в разные точки, никто не застревает
      в другом
- [ ] Респавн не ставит игрока в прямую видимость противника, если есть
      более безопасная точка
- [ ] Карта без маркеров `s` (старая копия) грузится и даёт осмысленные
      автоспавны
- [ ] Solo-режим по-прежнему стартует с `P`
- [ ] Точка спавна никогда не оказывается внутри стены или закрытой двери

## Замечания

Скоринг спавна — главный инструмент против спавн-килла, но не единственный:
на 10 игроках он обязан работать вместе с неуязвимостью после респавна
(09-02) и достаточно большой картой (09-07). По отдельности ни одно из трёх
не спасает.

Штраф за недавнее использование точки не даёт «спавн-петли», когда игрока
раз за разом кидает в одно и то же место к поджидающему противнику.
