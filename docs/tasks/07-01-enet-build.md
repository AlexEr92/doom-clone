# 07-01 — Подключить ENet к сборке

**Неделя:** 7 — Сеть: транспорт, протокол, снапшоты
**Зависит от:** —
**Блокирует:** 07-02
**Оценка:** ~40 строк в `CMakeLists.txt`

## Контекст

Нужен UDP с надёжными каналами, фрагментацией, учётом RTT и обнаружением
разрывов. SDL2_net этого не даёт (голые сокеты), писать своё — отдельный
проект. ENet — ~10k строк на C, MIT, без зависимостей, есть в пакетных
менеджерах всех целевых платформ.

Задача независима от остальных — можно делать параллельно с неделями 5–6.

## Что сделать

- [ ] `find_package(enet)` в `CMakeLists.txt` с fallback на `pkg_check_modules`
      (в разных дистрибутивах ENet поставляется по-разному: где-то есть
      CMake-конфиг, где-то только `.pc`, где-то только заголовки + `.so`)
- [ ] Опция `-DVENDOR_ENET=ON` — сборка из `vendor/enet/` для платформ, где
      системного пакета нет; вендорить как submodule или копией исходников
- [ ] На Windows ENet требует линковки `ws2_32` и `winmm` — добавить условно
- [ ] Опция `-DENABLE_MULTIPLAYER=ON/OFF` (по умолчанию ON): при OFF сетевые
      файлы не компилируются и ENet не ищется, собирается чистая одиночная
      игра. Полезно и как страховка, и для платформ без ENet
- [ ] Проверить сборку: Linux (apt), macOS (brew), Windows (MSYS2 и vcpkg)

## Затрагиваемые файлы

`CMakeLists.txt`, `vendor/enet/` (опционально), `README.md`

## Критерий готовности

- [ ] `cmake -S . -B build && cmake --build build` проходит на Linux
      с `libenet-dev`
- [ ] `cmake -S . -B build -DENABLE_MULTIPLAYER=OFF` собирает бинарь без
      единой ссылки на ENet (`ldd build/doom-clone | grep enet` — пусто)
- [ ] `-DVENDOR_ENET=ON` собирается на машине без системного ENet
