# bug-010 — Спрайт сплющивается, когда не помещается в экран сверху

## Что происходит

`sprite_render()` (`sprite.c`) обрезает верх спрайта по краю экрана:

```c
if (drawStartY < 0) {
    drawStartY = 0;
}
```

а выборку по текстуре начинает с нуля независимо от того, обрезал он
что-нибудь или нет:

```c
float stepY = (float)texH / (float)spriteHeight;
float texPos = 0.0f;
```

То есть кадр целиком укладывается в оставшиеся строки: чем ближе спрайт,
тем сильнее он сплющен по вертикали, хотя должен уходить за край экрана.
На расстоянии, где спрайт выше экрана, видно всю фигуру, сжатую в высоту,
вместо её верхней части.

По горизонтали той же ошибки нет: `texX` считается от неотсечённого
`spriteScreenX`, а не от обрезанного `drawStartX`.

## Как воспроизвести

Воспроизведение из `bug-009` с подходом вплотную: на глубине около 1.0
залитый кадр 64×64 меряется как 120×266 пикселей фреймбуфера — при верной
обрезке ширина и высота видимой части должны сохранять отношение кадра,
а не расходиться втрое.

## Что сделать

- [ ] Запомнить неотсечённый верх спрайта до присваивания `drawStartY = 0`
      и начинать выборку с него:
      ```c

      ```
