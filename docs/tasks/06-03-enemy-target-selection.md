# 06-03 — ИИ: выбор цели среди N игроков

**Этап:** 6 — Мультиплеерная логика локально
**Зависит от:** 06-02
**Блокирует:** —
**Оценка:** ~60 строк изменений
**Приоритет:** средний — враги есть только в co-op, который является
вторым режимом. Можно отложить до конца этапа 6

## Контекст

`enemy_update_all()` (`enemy.c:88-152`) принимает единственного `Player *pl`,
считает дистанцию до него (`enemy.c:96-99`), преследует его
(`enemy.c:119-122`) и напрямую мутирует `pl->hp` (`enemy.c:137`).

## Что сделать

- [ ] Сигнатура:
  ```c
  void enemy_update_all(EnemyList *el, const Map *m, DoorList *dl,
                        PlayerState *players, int player_count,
                        EventQueue *ev, double dt);
  ```
- [ ] Добавить в `Enemy` (`enemy.h:27-36`) поле `int target;`
      (id игрока или -1)
- [ ] Выбор цели: ближайший **живой** игрок в пределах `detect_range`
      с линией видимости (`world_line_of_sight()` из 05-03).
      При равенстве дистанций — меньший `id` (детерминизм)
- [ ] Цель пересматривается: в `IDLE`/`ALERT` — каждый тик; в `CHASE`/`ATTACK`
      — раз в 0.5 с или сразу при смерти/пропаже цели из виду
- [ ] `enemy_damage()` — вместо `px, py` для аудио писать событие
      `EV_ENEMY_HURT`/`EV_ENEMY_DEATH` с координатами врага в `EventQueue`
- [ ] Урон наносится игроку `e->target`; расчёт брони (`enemy.c:129-138`)
      без изменений, но по конкретному игроку
- [ ] Агрессия при попадании (`enemy.c:176-179`) — передавать в
      `enemy_damage()` id стрелявшего, чтобы враг переключался на него

## Затрагиваемые файлы

`enemy.h/.c`, `world.c`, `weapon.c`

## Критерий готовности

- [ ] Десять игроков в мире: враг атакует ближайшего видимого,
      выбор цели детерминирован (при равной дистанции — меньший `id`)
- [ ] Два игрока в мире: враг атакует ближайшего видимого
- [ ] Игрок стреляет в врага, который бьёт другого игрока → враг
      переключается на стрелявшего
- [ ] Цель умерла → враг находит следующего или уходит в `IDLE`
- [ ] Одиночная игра не изменилась

## Замечания

Пересмотр цели каждый тик даёт «дрожание» между двумя игроками на равной
дистанции и выглядит глупо — отсюда таймер 0.5 с в состояниях преследования.

Преследование без линии видимости разбирается отдельно в
[bug-001](bug-001-enemy-sees-through-walls.md): враг идёт на текущую позицию
игрока, а не на последнюю виденную. Задачи независимы, но если bug-001
делается первым, поля `last_seen_*` здесь нужно привязать к выбранной цели.
