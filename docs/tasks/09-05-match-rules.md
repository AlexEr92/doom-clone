# 09-05 — Правила матча и баланс deathmatch

**Этап:** 9 — Deathmatch, геймплей и меню
**Зависит от:** 09-03, 08-05
**Блокирует:** —
**Оценка:** ~150 строк изменений

## Контекст

`main.c:177` — победа при `enemy_all_dead()`, то есть матч кончается, когда
зачищена карта. Для deathmatch нужны фраг-лимит и лимит времени, а весь
баланс оружия придётся пересобрать: `weapon.c:10-19` подобран под врагов
с 30–60 хп, а не под игроков со 100 хп и бронёй.

## Что сделать

- [ ] Режимы матча:
  ```c
  typedef enum { MODE_DEATHMATCH = 0, MODE_COOP } MatchMode;
  ```
      `MODE_DEATHMATCH` — по умолчанию. Выбирается хостом, приезжает
      клиенту в `MSG_ACCEPT` (07-03)
- [ ] **Deathmatch:** враги не спавнятся (маркеры `E`/`S` игнорируются),
      PvP-урон включён, конец по лимиту фрагов (30) или времени (10 мин).
      Таймер матча и лидер — в HUD
- [ ] **Co-op:** враги активны, PvP-урон выключен, победа — зачистка карты.
      Сложность по числу игроков: `hp` врагов ×`(1 + 0.4*(N-1))`.
      При 10 игроках это ×4.6 — стоит вместо этого доспавнивать врагов,
      иначе имп с 138 хп выглядит нелепо
- [ ] Экран результатов: финальная таблица, `PLAY AGAIN` / `QUIT TO MENU`
- [ ] Рестарт матча без переподключения: сервер перезагружает мир, шлёт
      клиентам сигнал сброса; клиенты чистят буферы снапшотов и историю
      вводов (08-01, 08-02)

## Баланс PvP

Это основная работа задачи, а не довесок. Текущие числа под врагов:

| | урон | скорострельность | DPS | выстрелов до убийства (100 хп) |
|---|---|---|---|---|
| Пистолет | 15 | 0.45 с | 33 | 7 |
| Дробовик | 7×10 = 70 | 0.85 с | 82 | 2 |

- [ ] Отдельный множитель урона по игрокам (`PVP_DAMAGE_SCALE`) — чтобы
      не ломать баланс co-op при подстройке DM
- [ ] Дробовик в упор убивает за 2 выстрела и радикально доминирует —
      либо снизить урон дробины, либо усилить спад урона с дистанцией
      (сейчас его нет вовсе: попадание на 10 клетках = попадание в упор)
- [ ] Пистолет с 7 выстрелами до убийства при 0.45 с — это 3 секунды
      непрерывного попадания, в DM неиграбельно. Поднять урон или темп
- [ ] Коэффициент поглощения бронёй (0.5, зашит в `enemy.c:131-135`) —
      вынести в константу и подобрать для PvP отдельно
- [ ] Стартовый боезапас и `max_ammo` (`weapon.c:11,16`) под темп DM
- [ ] `PLAYER_HIT_RADIUS` (05-04) — финальная подстройка здесь

## Критерий готовности

- [ ] Deathmatch до 30 фрагов и до 10 минут заканчивается экраном
      результатов
- [ ] Co-op вдесятером не проходится за минуту
- [ ] `PLAY AGAIN` перезапускает матч, никого не отключая
- [ ] После рестарта клиенты не показывают призраков из старого матча
- [ ] Матч 4×4 длится осмысленное время, ни одно оружие не доминирует
      полностью
- [ ] Ни одно оружие не убивает с одного попадания

## Замечания

Рестарт без переподключения — место, где легче всего получить рассинхрон:
у клиента остаются старые снапшоты, неподтверждённые вводы и номера тиков.
Надёжнее всего сбрасывать `tick` в 0 и требовать полной переинициализации
мира, игнорируя снапшоты до подтверждения сброса.

Баланс невозможно подобрать в одиночку — нужен реальный тест хотя бы на
4 живых игроках. Заложить время на несколько итераций после того, как
всё заработает технически.

Спад урона дробовика по дистанции — не в текущем коде вовсе, и в
одиночной игре это не мешало. В deathmatch дробовик, бьющий на всю карту
через 7 дробин, ломает игру. Это правка в `weapon_try_fire()` (05-04),
но обнаруживается только здесь.
