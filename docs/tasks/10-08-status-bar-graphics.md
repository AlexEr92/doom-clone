# 10-08 — Графика статус-бара: лицо, иконки, прицел

**Этап:** 10 — Графика и арсенал
**Зависит от:** 10-05, 10-01
**Блокирует:** —
**Оценка:** ~150 строк изменений

## Контекст

Статус-бар рисуется кодом целиком: `hud_draw_face()` (`hud.c:116-166`)
складывает лицо из прямоугольников — фон, кожа, глаза, рот, который
меняется по `hp_frac`; числа выводит шрифт 3×5 (`hud.c:7-18`). Текущее
оружие в панели никак не показано — понять, что в руках, можно только по
картинке ствола внизу экрана, а после 10-05 стволов пять.

Прицела в игре нет вовсе.

## Что сделать

- [ ] `assets/hud/face_48x48.png`, 7 кадров: пять по здоровью, гримаса
      боли, мёртвый. `hud_draw_face()` рисует кадр из листа, когда он
      загружен, и остаётся процедурной, когда файла нет
- [ ] Выбор кадра: бакет по здоровью; гримаса боли на фиксированное время
      после получения урона; мёртвый кадр при нулевом здоровье
- [ ] `assets/hud/icon_<оружие>_32x16.png` — иконка текущего оружия в
      панели. Рядом с ней подобранные стволы показываются номерами клавиш:
      подобранный ярко, неподобранный тускло
- [ ] `assets/hud/crosshair_32x32.png` в центре экрана; при отсутствии
      файла прицела нет, как сейчас
- [ ] Всё перечисленное — в таблицу слотов из 10-01

## Затрагиваемые файлы

`src/hud.c`, `src/hud.h`, `src/assets.h`, `src/assets.c`

## Критерий готовности

- [ ] Без файлов графики статус-бар выглядит ровно как сегодня
- [ ] С файлами: лицо меняется по здоровью, дёргается при попадании,
      показывает мёртвый кадр после смерти
- [ ] Иконка соответствует оружию в руках при каждом переключении
- [ ] Подобранные и неподобранные стволы различимы в панели
- [ ] `driver.sh smoke` проходит

## Замечания

Прозрачность в иконках работает так же, как везде: пиксель с альфой 0
пропускается, остальные рисуются непрозрачными. Панель под иконкой
непрозрачная, так что полутонов по краю не будет видно только при жёстком
крае в исходнике.

Скорборд (09-03) рисует свои строки тем же шрифтом 3×5 и этой задачей не
затрагивается.
