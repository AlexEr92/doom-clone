## Контекст

`README.md` описывает одиночную игру: возможности, сборку, управление.
Сборка с ENet в нём уже описана — submodule `vendor/enet/` и
`-DENABLE_MULTIPLAYER=OFF`, — как и маркер точки спавна `s` и две карты:
`level1.txt` для одиночной игры, `dm1.txt` для сервера, выбор `--map`.
Запуск сетевой игры не описан вовсе, хотя флаги работают с 07-07.

## Замечания

Проверка README копипастом — не формальность: команды сборки в нём
устаревают первыми. Идеально — прогнать на чистом контейнере
(`docker run --rm -it debian:stable`), это заодно ловит незадекларированные
зависимости.
