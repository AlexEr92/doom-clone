**Откуда:** замечено при выносе шрифта в `text.c` (test-003)
**Зависит от:** —
**Блокирует:** —
**Оценка:** 1 строка в таблице `src/text.c` + ~50 строк нового `tests/manual/text_shot.c` и регистрация в `tests/CMakeLists.txt` и `tests/README.md`; размер инструмента оценён по `hud_shot.c`, который делает то же для статус-бара
**Приоритет:** низкий: чисто косметика, и пока ни одна строка на экране не содержит `!` — видно станет только когда содержит

## Контекст

### Что происходит

Маска глифа `!` в `src/text.c`:

```c
static const uint8_t bang[TEXT_GLYPH_H] = {0b010, 0b010, 0b010, 0b010, 0b000};
```

Это сплошная палка в центральной колонке на строках 0–3 и пустая нижняя
строка 4. Восклицательный знак должен быть «палка, пропуск, точка»:
`{0b010, 0b010, 0b010, 0b000, 0b010}`. Форма пришла из `draw_char()` в
`game.c`, где комментарий описывал именно «столбик, пропуск, точка», а таблица
этого не делала; при выносе в `text.c` форму оставили как есть, чтобы
вынос не поменял ни одного пикселя.

Сейчас на экране `!` не виден: `grep -n '"[^"]*!' src/game.c` не находит
строк с ним. Ошибка проявится, как только его использует оверлей, меню или
kill feed.

### Как воспроизвести

Нарисовать `text_draw_char(fb, x, y, '!', color, scale)` и посмотреть на
строку 4 (нижнюю): пуста, а строка 3 закрашена. Так как в игре
такой строки нет, воспроизведение — через инструмент из пункта ниже; до его
появления — через временную строку с `!` в любом оверлее `game.c`.

## Замечания

`tests/test_text.c` формы глифов намеренно не знает (см. комментарий в его
шапке), поэтому форму `!` тест не закрепляет и закреплять не должен: её
проверяют глазами, на то и инструмент.

Другие задачи правят ту же таблицу: 09-04 добавляет `.` и `_`, 08-04
рисует `.`, `%`, `/` (см. примечание в каждой). Независимо от порядка
конфликтов по строкам таблицы нет: каждая добавляет свои `static const`
и `case`. Инструмент `text_shot` общий — кто пришёл первым, тот его и
создаёт; если он уже есть, остальные только дописывают символы.

Отдельной задачи на «картинку из шрифта» не заведено: она нужна ровно для
глифов и закрывает все три случая.
