# 08-01 — Буфер снапшотов и интерполяция

**Этап:** 8 — Качество netcode
**Зависит от:** 07-05
**Блокирует:** —
**Оценка:** ~180 строк нового кода

## Контекст

Снапшоты приходят на 20 Гц, рендер идёт на 60+ FPS. Без интерполяции чужие
игроки и враги двигаются рывками по три кадра.

Приём: рендерить не последнее состояние, а состояние на 100 мс в прошлом,
интерполируя между двумя снапшотами, которые его окружают. Задержка в 2
снапшота даёт запас на потерю одного пакета.

## Что сделать

- [ ] Кольцевой буфер снапшотов на клиенте:
  ```c
  #define SNAPSHOT_HISTORY 8
  typedef struct {
      MsgSnapshot snaps[SNAPSHOT_HISTORY];
      double      recv_time[SNAPSHOT_HISTORY];
      int         head, count;
  } SnapshotBuffer;
  ```
- [ ] `#define INTERP_DELAY 0.100` — время рендера = `now - INTERP_DELAY`
- [ ] Поиск пары снапшотов вокруг целевого времени + коэффициент `t ∈ [0,1]`
- [ ] Интерполяция по сущностям:
  - позиции — линейно
  - `angle` — по **кратчайшей дуге**: `a + wrap_pi(b - a) * t`
    (наивный lerp даст оборот на 360° при переходе через ±π)
  - `hp`, состояние ИИ, оружие — не интерполируются, берутся из старшего
    снапшота
  - сущность, отсутствующая в одном из снапшотов (спавн/деспавн),
    не интерполируется
- [ ] Результат интерполяции идёт **только в рендер** — в
      `sprites_build_from_world()` (06-05); симуляционный `World` не трогаем
- [ ] Экстраполяция при нехватке снапшотов: продолжить движение по последней
      скорости, не дольше 250 мс, дальше — заморозить

## Затрагиваемые файлы

`net_client.c/.h`, `world.h` (буфер для рендер-состояния), `main.c`

## Критерий готовности

- [ ] Чужой игрок движется плавно при 20 Гц снапшотов и 60 FPS
- [ ] Искусственная потеря 10% пакетов не даёт видимых рывков
- [ ] Игрок, поворачивающийся через границу ±π, не делает оборота
- [ ] Локальный игрок интерполяцией **не** затрагивается (он пойдёт через
      предсказание, 08-02)

## Замечания

Проверять с `tc netem`:
```bash
sudo tc qdisc add dev lo root netem delay 75ms 10ms loss 10%
sudo tc qdisc del dev lo root                     # снять
```

100 мс задержки означает, что вы видите противников на 100 мс в прошлом.
Это плата за плавность и стандартный компромисс; частично компенсируется
лаг-компенсацией на сервере (08-05).
