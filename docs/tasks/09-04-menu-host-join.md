# 09-04 — Меню HOST/JOIN и ввод IP

**Неделя:** 9 — Мультиплеерный геймплей и меню
**Зависит от:** 07-07
**Блокирует:** 09-06
**Оценка:** ~200 строк изменений

## Контекст

FSM игры (`game.h:8-14`) — `MENU → PLAYING → PAUSED → DEAD → WIN`, навигация
по одиночным клавишам (`game.c:125-189`). Ввода текста нет вообще: шрифт 3×5
(`game.c:8-48`) умеет только рисовать.

Пока адрес задаётся только через `--connect` (07-07); для нормального
запуска нужен экран подключения.

## Что сделать

- [ ] Новые состояния в `GameState`:
  ```c
  GSTATE_MENU, GSTATE_HOST_SETUP, GSTATE_JOIN_SETUP,
  GSTATE_CONNECTING, GSTATE_LOBBY, GSTATE_PLAYING, ...
  GSTATE_DISCONNECTED
  ```
- [ ] Главное меню: пункты `SINGLE PLAYER / HOST GAME / JOIN GAME / QUIT`
      с выбором стрелками и Enter (сейчас Enter сразу стартует игру)
- [ ] Простая строка ввода: `SDL_StartTextInput()` + `SDL_TEXTINPUT`
      в `input.c` (сейчас обрабатываются только `SDL_KEYDOWN`/`KEYUP`);
      Backspace, ограничение длины, мигающий курсор
- [ ] `GSTATE_JOIN_SETUP` — поля адреса, порта и имени; значения по умолчанию
      `127.0.0.1` / `27015`, сохраняются между запусками в файл настроек
- [ ] `GSTATE_CONNECTING` — `CONNECTING...` с таймаутом 5 с и отменой по ESC
- [ ] `GSTATE_LOBBY` — список подключившихся, старт по Enter у хоста
      (или сразу в игру, если лобби избыточно для демо)
- [ ] `GSTATE_DISCONNECTED` — `CONNECTION LOST` + причина + возврат в меню
- [ ] Пауза в сетевой игре **не останавливает мир** (в отличие от
      `main.c:156` в solo) — только оверлей; мышь освобождается

## Затрагиваемые файлы

`game.h/.c`, `input.h/.c`, `text.c/.h`, `net_client.c`, `main.c`

## Критерий готовности

- [ ] Игра запускается и подключается полностью из меню, без флагов
      командной строки
- [ ] Ввод IPv4-адреса работает, включая точки и Backspace
- [ ] Отмена подключения по ESC не оставляет висящих сокетов
- [ ] Разрыв связи ведёт на экран `CONNECTION LOST`, а не в падение
- [ ] Флаги командной строки (07-07) продолжают работать в обход меню

## Замечания

Шрифт 3×5 (`game.c:8-48`) поддерживает только `A-Z`, `0-9` и символы
`: - !` — для IP нужна точка. Добавить глифы `.` и `_` в `draw_char()`
(модуль `text.c`, вынесенный в 08-04).

`SDL_StartTextInput()` / `SDL_StopTextInput()` нужно парно переключать при
входе и выходе из полей ввода, иначе в игре клавиши будут дублироваться
как текст.

Мышь: в игре захватывается (`SDL_SetRelativeMouseMode`), в меню должна
отпускаться — сейчас режим захвата вообще не переключается.
