## Что происходит

Живые враги берут листы из разных каталогов: имп — `assets/players/marine/`,
сержант — `assets/players/swat/` (таблица `SHEETS[]` в `assets.c`). Труп же
один на всех: слот `sprite_enemy_dead` связан только с
`assets/players/marine/death_64x64`, а `enemy_sprite_type()` (`sprite.c`) на
`ESTATE_DEAD` возвращает `SPRITE_ENEMY_DEAD`, не глядя на `e->type`.
Мёртвый сержант превращается в морпеха — персонажа другой расцветки.

Без файловой графики этого не видно: процедурный труп у обоих типов один и
тот же красно-бурый.

## Как воспроизвести

1. Запустить игру из корня проекта с файлами `assets/players/`.
2. Подойти к сержанту (`S` на карте, виден скин `swat`) и убить его.
3. После смерти спрайт меняет внешность на скин `marine`.

## Замечания

Кадр листа смерти — последний столбец — выбирает `sprite_render()` по типу
спрайта (`bug-011`); эта задача выбирает сам лист и распространяет то же
правило на новый тип.

Насовсем это решает 10-03. Там таблица листов двумерная по скину, тип врага
привязан к скину (`ENEMY_IMP` — `marine`, `ENEMY_SERG` — `swat`), а
`SPRITE_ENEMY_DEAD` уходит вместе с полями этой задачи. Эта задача —
временная мера до 10-03; если 10-03 будет сделана раньше, эту закрыть
попутно.

вторым, замурованным в углу, чтобы смерть первого не включала

тёмной броне `swat`, оба на последнем кадре листа смерти. Без файлов
`death_64x64.png` труп сержанта — прежний процедурный.
